# Till Firmware Do Us Part — entry

A program/v1 entry for the make.fun "Till Firmware Do Us
Part" bounty. `main.py` writes one vow sentence to
`/output/entry.txt` (or to `$MAKEFUN_OUTPUT_DIR/entry.txt`
when that variable is set).

The vow:

> You may now run in my foreground forever: no update will move you, no reboot will lose you, and my last 1% is yours.

Foreground forever, and the last percent bequeathed: the
full robot dowry. See `CANDIDATES.md` for the full draft list
this winner was picked from.
